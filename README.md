# BlackJack — Pygame 카드 게임

Python과 Pygame으로 구현한 GUI 블랙잭 게임입니다. 카드 덱과 손패의 점수 계산을 클래스로 분리하고, 화면의 버튼으로 카드 배분·추가·승패 확인·재시작을 처리합니다.

## 주요 기능

- 4개 무늬와 13개 랭크로 구성한 52장 카드 덱 생성 및 셔플
- 카드 이미지를 이용한 플레이어·딜러 손패 표시
- `Deal`, `Hit`, `Stand` 버튼을 이용한 게임 진행
- A를 1 또는 11로, J·Q·K를 10으로 계산하는 손패 점수 처리
- 블랙잭·버스트·승리·패배·무승부 결과 표시와 새 게임 시작

## 기술과 구성

**Python 3 · Pygame · 객체 지향 프로그래밍 · GUI 이벤트 처리**

| 파일 | 역할 |
| --- | --- |
| `blackjack_pygame.py` | 게임 창, 버튼 이벤트, 카드 표시와 게임 진행 |
| `blackjack_deck.py` | `Deck`·`Hand` 클래스와 손패 점수 계산 |
| `constants.py` | 화면 크기, 색상, 글꼴, 카드 무늬·랭크 정의 |
| `blackjack_calc_hand.py` | 카드 배분과 점수 계산을 확인하는 보조 스크립트 |
| `img/` | 카드 앞면·뒷면 및 배경 이미지 |

## 실행

Python 3와 GUI를 표시할 수 있는 환경이 필요합니다. 별도 빌드 과정은 없으며 Pygame을 설치한 뒤 저장소 루트에서 실행합니다.

```bash
git clone https://github.com/JDW1224/OpenSW_MiddleProject.git
cd OpenSW_MiddleProject
python -m pip install pygame
python blackjack_pygame.py
```

카드 이미지를 `img/` 상대 경로로 읽으므로 실행할 때 현재 작업 폴더가 저장소 루트여야 합니다.

## 조작 방법

1. **Deal**: 새 게임의 카드를 배분합니다.
2. **Hit**: 플레이어 카드를 추가로 받습니다.
3. **Stand**: 현재 손패로 딜러와 점수를 비교합니다.
4. 게임이 끝나면 **Deal**을 눌러 다시 시작합니다. **EXIT** 또는 창 닫기로 종료합니다.

## 현재 제약

**처음 시작하거나 게임 종료 후 재시작할 때는 반드시 Deal을 먼저 눌러야 합니다.** Deal 없이 Hit 또는 Stand를 누르면 초기화되지 않은 카드 상태로 인해 오류가 발생할 수 있습니다. 원본 [읽어주세요!!](./읽어주세요!!)에 기록된 문제입니다.

현재 코드는 간소화한 게임 규칙을 사용합니다. Stand 시 딜러가 추가 카드를 받는 규칙, 베팅, 스플릿 등은 포함되어 있지 않으며, 여러 차례 Hit할 때의 카드 표시와 종료 처리에도 제약이 있습니다.
